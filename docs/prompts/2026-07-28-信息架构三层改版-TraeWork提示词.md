## 提示词正文（复制从下一行开始）

```
你是产品/交互设计师兼前端实现者。请为「可视化刻意练习系统」做信息架构高保真改版（方案 C：双轨入口 + 主题总览 + 单模式作业面）。直接产出可打开的 HTML，延续现有 Trae 设计体系。

【背景矛盾】
- 主轴已能走通，但用户体感「说不上来的别扭」：当前把入口、主题总览、计划/执行/复盘/改进全堆在同一工作台，一看很杂。
- 用户已定三层：
  1）入口：按 1～2 个维度极简聚合——「今天」+「主题」，两者都有但极简；
  2）主题页：单主题看板，侧重总览；
  3）作业层：计划（含阶段管理）、执行、复盘、改进——不要四栏等权常驻，要一眼能聚焦当天重点。
- 选定方案 C：L1 默认同时给「今天」精简条 +「我的主题」少数卡片；进主题先 L2 总览；L3 默认落在「执行」，计划/复盘用明确入口进入。
- 反模式：再做一个「啥都有」的四栏驾驶舱当首页；L2 重复 L3 的全部控件；槽位/漂移/系统约束压过「今日任务」。

【产品锚点】
- 总纲：docs/requirements/2026-07-23-可视化刻意练习系统-需求澄清.md
- 阶段/并发：docs/requirements/2026-07-27-主题计划阶段与并发-需求澄清.md
- 设计：docs/specs/2026-07-27-主题计划阶段与并发-design.md

  - prototype/pages/theme-plan-phases.html → L3·计划（阶段/槽位/主焦点）或并入「计划」模式的子区
  - prototype/pages/weekly-review.html → L3·复盘与改进
  - prototype/pages/new-theme-intercept.html → 从 L1「新建主题」进入
- prototype/.design：登记新页、更新 interactions；相对 href + data-dom-id 双轨；浏览器直开可走通。

【三层职责（硬约束）】

L1 · 入口（新首页，极简）
- 只回答：「今天干什么 / 进哪个主题」。
- 必须同时有且保持极简：
  A. 「今天」：跨主题今日任务精简列表（每条：主题名 + 任务一句 + 勾选或进入）；任务很少（总共 2～5 条量级）。
  B. 「我的主题」：2～4 张主题卡即可（示例：革新学习方法·学习期·主焦点；矛盾论·练习续跑）。卡上最多：阶段、一句状态、是否今日有任务；不要 KPI 墙、不要 PDCA 四栏。
- 全局次要：新建主题（→ 拦截页）、槽位占用一行小字（如 学1/1 练1/3 用0/5）。
- 禁止：四栏 PDCA、大块复盘、共创对话、完整漂移时间线出现在 L1。

L2 · 主题看板（单主题总览）
- 只回答：「这个主题整体怎样、下一步建议做什么」。
- 一屏可读完：主题名与阶段、核心掌握摘要（3/5 可展开）、当前切片一句话/短清单、今日任务入口（主 CTA）、一条风险或漂移提示（可链到详情）、并行主题若存在仅一行提示。
- 明确入口进入 L3 各模式：执行（默认强调）、计划、复盘与改进。
- 禁止：把完整共创对话、完整阶段管理台、完整周复盘表单全部内嵌进 L2 首屏。

L3 · 作业面（单模式聚焦）
- 一次只突出一种模式，用顶部分段/Tab 或等价切换：
  1. 执行（默认）：今日任务为主焦点区；来源汇入/同步降为次要。
  2. 计划：当前切片 + 打开共创；阶段切换/槽位/主焦点放在计划模式内（可复用/链到 theme-plan-phases，但须有返回 L2）。
  3. 复盘与改进：复盘流程 + 改进建议采纳（C/A 合并为一条作业流，不要与执行长期四等分）。
- 每一模式：一屏一个主焦点区；其余折叠或弱化。
- 学习期进行中时，「进入下一阶段」不得成为比「今日任务」更抢眼的全局主按钮。

请明确采用并实现其一：

无论哪种：从 L1 出发浏览器点击须能到 L2、L3 各模式，并返回；.design 完整登记。

【示例数据】
- 主主题：革新学习方法（学习期，主焦点之一）。
- 并行：矛盾论（练习续跑，可占第二主焦点以演示漂移入口，但 L1/L2 表述要清醒）。
- 「今天」列表同时出现两主题各至少 1 条任务（体现双轨入口价值）。
- 时长与条目继续遵守愿用性：约 30 分钟/天；切片与今日任务同语义场。

【视觉与交互】
- 延续 Trae dark token、组件、图标路径；桌面优先。
- L1 第一屏必须「疏」：大留白可接受，禁止再堆四张 KPI + 四栏。
- L2 像看板/摘要，不像后台表格。
- L3 像作业台：主区足够大，次要信息不抢主 CTA。
- 假数据前端模拟即可；不接真实 LLM/后端。

【验收清单】
1. 打开产品默认是 L1，不是四栏工作台。
2. L1 同时有「今天」与「主题卡」，且仍显极简（无 PDCA 四栏）。
3. 点主题卡进入 L2 总览；L2 能一句话说清阶段与下一步。
4. 从 L2 进入 L3，默认落在「执行」；计划 / 复盘与改进可切换且不四栏等权常驻。
5. 新建主题从 L1 出发 → 拦截 → 可回 L1 或 L2。
6. 既有共创/阶段/复盘能力可到达，不丢主路径；.design 与 href 对齐。
7. 用户能回答：我现在在第几层、这一屏只该干什么。

- 不要在 L1 展示完整漂移时间线、完整槽位管理台。
- 不要低保真线框作为主交付。
```
