# 主题概览 L2 推翻重做（方案 1 · 单栏叙事）· Trae Work 提示词

> 用法：将下方「提示词正文」整段复制到 Trae Work。  
> 请同时打开：三层 IA 交付、冷启动 first 看板、当前 `theme-overview.html`（作废对象，非照抄）。  
> 目标：**定位不变**（单主题整体概览），但**推翻当前仪表盘式双栏看板**，按单栏叙事重做。  
> 注：延续已修好的 Trae dark 壳与图标；不要新视觉语言，不要把修壳当主任务。

## 提示词正文（复制从下一行开始）

```
你是产品/交互设计师兼前端实现者。请推翻重做「可视化刻意练习系统」的 L2 主题概览高保真原型。直接产出可打开的 HTML。

【为什么推翻】
- 当前 theme-overview.html 像后台仪表盘：摘要条 + 今日 CTA + 核心 + 切片 + 下一步建议 + 风险黄条 + 并行主题 + 三模式入口等权堆叠。
- 用户体感：首次进入关注点太多；回访又觉得很多信息没必要。根因不是「少两张卡」，而是页面物种错了——总览被做成了运营驾驶舱。
- 定案：定位仍是「单主题整体概览」，但页面结构推翻重做；学习进度必须保留；不要在旧双栏上打补丁。

【产品定案（不可改）】
1. 定位：L2 = 这个主题整体怎样（概览），不是 L3 作业台，也不是多主题首页。
2. 布局：方案 1 · 单栏叙事（自上而下一条故事线）。禁止默认双栏信息墙。
3. 结构地图：核心清单 + 三阶段路径都要，但按阶段切换主辅：
   - 学习期：主地图 = 核心掌握清单；辅 = 学→练→用精简路径条
   - 练习期 / 应用期：主地图 = 三阶段路径（当前位置高亮）；辅 = 核心掌握一行（如 3/5，可展开）
4. 主流学习产品概览只保留六类元素（按此组织，勿加第七类当默认）：
   ① 身份  ② 整体进度  ③ 唯一主行动  ④ 本阶段主地图  ⑤ 当前位置/下一步（可并入主行动）  ⑥ 次要入口
5. 明确降级或移除出默认首屏：
   - 「下一步建议」列表（若与今日任务重复则整块删除；最多异常时一句）
   - 常驻「注意力分散 / 漂移」黄条（无异常则不出现；有异常最多一行可点）
   - 「并行主题」独立卡片（有则并入次要入口或异常一行）
   - 执行/计划/复盘等权模式条（主 CTA 已是进入执行；计划/复盘降为次要文字链）

【单栏叙事 · 区块顺序（硬约束）】

自上而下固定：

A. 身份
- 主题名；当前阶段标签（学习期 / 练习期 / 应用期）；一句目标或阶段名即可。
- 不要再堆：槽位「学1/1」、W1、多个 tag 并排抢视线。槽位若要保留，放次要区或极弱小字。

B. 整体进度（必须有）
- 学习期示例：第 3/7 天 · 每天约 30 分钟 · 核心 3/5
- 练/用期示例：练习期进行中 · 已完成学习期 · 核心 4/5（或阶段内周次）
- 进度是摘要，不是 KPI 墙；一横条或一行数字即可。

C. 唯一主行动
- 「今日任务」2 项左右 + 主按钮「进入执行」（首次可用「开始第一天」）。
- 这是全页唯一品牌主按钮。不要第二个同级主按钮。

D. 本阶段主地图（随阶段切换）
- 学习期：展开展示约 5 条核心，每条有掌握态（已掌握 / 良好 / 待加强）；当前相关核心可轻提示。
- 练/用期：展示 学 → 练 → 用 路径；当前阶段高亮；已完成阶段可勾选/弱化；未到阶段可见但不可喧宾夺主。
- 主地图占视觉重心，但不要做成可滚动的巨型大纲树。

E. 辅地图（一行或可展开，勿与主地图同权）
- 学习期辅：精简三阶段路径条（当前位置一点即可）。
- 练/用期辅：核心 3/5 一行；点开才看清单。

F. 次要入口（弱）
- 文字链或轻量按钮：「调整计划」→ theme-plan-phases 或 L3 计划；「复盘」→ weekly-review 或 L3 复盘。
- 资料入口可选，同样弱。
- 禁止底部再做一套「进入模式」等权三按钮条与主 CTA 抢焦点。

【与冷启动 first 的关系】
- theme-overview-first.html 保持减法精神：锁定提示 + 今日主 CTA + 核心一行。
- 本轮回访概览与 first 同属「概览家族」，但回访要完整进度+主地图；不要把 first 堆回旧看板，也不要用旧看板污染 first。
- 从 first「开始第一天」之后的回访，落到新的 theme-overview.html。

【页面交付】
1. 重写 prototype/pages/theme-overview.html（回访 L2 · 学习期状态为默认打开态）
2. 必须能演示练/用期主辅切换，任选其一实现：
   - 推荐：另做 theme-overview-practice.html（练习期示例），或
   - 同页提供「演示：切换到练习期」控件（仅原型演示，勿做成产品功能）
3. 轻触 theme-overview-first.html：仅保证家族一致与链接落到新 overview；不要重新堆满
4. 更新从 home.html / home-after-first.html 点进主题卡的链接，指向新 overview
5. 更新 prototype/.design（相对 href + data-dom-id）

【示例数据】
- 主主题：革新学习方法（通识）
- 学习期页：学习期 · 第 3/7 天 · 每天约 30 分钟 · 核心 3/5
  - 今日任务 2 项（与现有语义一致即可：检视阅读 + 费曼复述一类）
  - 5 条核心含已掌握/良好/待加强
- 练习期演示页：阶段切换后主地图变为学→练→用；核心收成辅行
- 并行「矛盾论」不要做成默认首屏模块；若演示异常，最多一行弱提示
- 愿用性：每天约 30 分钟；核心约 5 条可见；勿用「10×2 小时」课表

【壳与视觉】
- 复制现有 app-shell / titlebar / activity rail / Trae dark token / 图标路径
- 参考壳：prototype/pages/home.html、theme-overview-first.html
- 旧 theme-overview.html 仅作「反模式参考」：它有什么杂，新页就不要什么
- 桌面优先；单栏内容区居中或限宽，留白要够，像学习产品概览，不像后台表格

【交互硬约束】
- 主 CTA → theme-work.html（执行）
- 返回 → home.html 或 home-after-first.html（与现链路一致）
- 次要「计划/复盘」可链到既有子页，须能返回 L2
- 无异常时不出现风险/漂移/并行块
- 假数据即可；不接真实 LLM/后端

【验收清单】
1. 打开新 L2，3 秒内能说出：主题是什么、进度到哪、今天点哪个按钮。
2. 学习期：核心清单是主地图；阶段路径只是辅。
3. 练习期演示：阶段路径是主地图；核心是辅。
4. 全页只有一个主按钮（进入执行）。
5. 首屏没有「下一步建议」列表、没有等权三模式条、没有常驻双栏卡片墙。
6. first 看板仍保持减法；回访概览有完整进度与主地图。
7. .design 与可点击路径对齐。

【本轮产出】
1. 上述 HTML + .design
2. 学习期 / 练习期两态点击说明（≤12 步）
3. 「有什么 / 刻意没有」短表（对照旧 overview）
4. ≤6 条假设与未做项

【明确不要】
- 不要在旧双栏上微调间距/收折冒充重做
- 不要恢复 KPI 墙、风险黄条常驻、并行主题卡、下一步建议列表
- 不要新视觉语言；不要低保真线框当主交付
- 不要改 L1/L3 主结构（接线除外）
- 不要把 L2 做成 L3 作业台

【语言】回复与界面文案使用简体中文。
```
