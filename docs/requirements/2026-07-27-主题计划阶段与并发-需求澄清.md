## 1. 本专题解决什么

总纲要求 P 阶段生成「学习 / 练习 / 应用」计划，但未规定三者是三份并列工程，还是同一主题下随时间演进的计划形态；也未定「主题未完成时能否开新学」的并发规则。

本专题澄清：

1. **计划形态**：一份主题计划生命周期，按阶段归档 + 新生成；  
2. **阶段与完成**：学习完成 ≠ 主题毕业；阶段由用户手动切换；  
3. **并发与漂移**：阶段槽位硬上限 + 主焦点手设与警告。

---

## 2. 痛点中的矛盾

| 立场 | 合理之处 | 若走极端 |
|------|----------|----------|
| 三者独立 | 学/练/用职责清晰 | 维护成本大于执行成本；简单系统更反脆弱 |
| 三者永远等权混合 | 相辅相成、少文档 | 忽视阶段比重与时长差：学习可短至数日，练习约月级，应用可达半年级 |

认识过程示例（《矛盾论》量级）：

- **学习阶段**：约 3 天（阅读 + 理解）  
- **练习阶段**：约 1 个月（用框架分析问题）  
- **应用成熟**：约半年（较随心所欲）  

因此：不能要求「主题应用成熟」才算可开新学；也不能在半年应用长尾里强制单线程空窗。

---

## 3. 决策结论

### 3.1 计划形态

- **一份计划**（按主题），不是 P 栏三份长期并排维护的独立计划工程。  
- **三个主题阶段**：学习 → 练习 → 应用；由用户**手动**切换。  
- 进入下一阶段时：**上一阶段计划标为已完成（只读归档）**，为当前阶段**新生成**对应计划（如学习计划完成 → 新生成练习计划）。  
- 任一阶段的计划内容都可以包含学 / 练 / 用活动，但**默认比重随当前阶段变化**；支持**手动局部修改**；练习期与应用期**不追求复杂精巧**。

默认比重倾向：

| 当前阶段 | 学 | 练 | 用 |
|----------|----|----|-----|
| 学习 | 强 | 弱 | 弱 |
| 练习 | 弱 | 强 | 中 |
| 应用 | 弱 | 弱 | 强 |

### 3.2 「完成」的定义

| 说法 | 含义 | 能否开新的学习期主题 |
|------|------|----------------------|
| 学习阶段完成 | 用户切入练习期；学习计划归档 | 能（学习槽释放） |
| 练习阶段完成 | 用户切入应用期；练习计划归档 | 通常能 |
| 应用成熟 / 主题毕业 | 长尾目标，非硬门禁 | 不作为开新学的前提 |
| 主题休眠 / 废弃 | 用户主动挂起或关闭 | 释放所占槽位 |

### 3.3 阶段槽位（全局硬拦）

同时处于各阶段的主题数上限：

| 阶段 | 上限 |
|------|------|
| 学习 | **1** |
| 练习 | **3** |
| 应用 | **5** |

触顶：**硬拦住**（不可再把主题推进该阶段 / 不可新建并直接落入已满阶段），除非先切换阶段、休眠或废弃以腾出名额。

### 3.4 主焦点（与阶段正交）

- 由用户**手动**设置；**数量上限 3**；不限主题处于哪一阶段。  
- 主焦点 **= 1**：正常。  
- 主焦点 **> 1 且 ≤ 3**：允许，但 **强警告 + 记入计划漂移**。  
- 主焦点 **> 3**：不可再设（硬顶）。

阶段槽管「认识过程带宽」；主焦点管「注意力是否摊薄」。两者同时生效。

## 4. 对总纲的修订关系

总纲仍成立：AI 重 P，人重 D；可视化刻意练习；主题工作台 PDCA。

本专题**修正/细化**的理解：

- 「生成学习 / 练习 / 应用计划」→ 解释为**随阶段归档 + 新生成**，而非三份需同时维护的计划工程。  
- 「新建主题拦截 / 计划漂移」（总纲 §9.5）→ 本专题定为：阶段硬容量 + 主焦点 >1 记漂移；**不**采用「任何未毕业主题都禁止新学」。

仍留待后续专题：练习/应用任务的最小字段与完成判定、对话共创在练习/应用期是否复用同一交互壳等。

---

## 5. 成功标准（本专题）

1. 用户能说清：当前主题在哪一阶段、哪一截计划可编辑、上一截是否已归档。  
2. 学习期结束后可以立刻开另一个主题的学习期（在学习槽规则下），同时旧主题以练习/应用续跑。  
3. 试图突破 1+3+5 时被硬拦，且文案说明如何腾槽。  
4. 主焦点多于 1 个时有强警告，且漂移可被事后看见（C/可视化可消费）。  
5. 练习/应用计划明显比学习课表更短、更糙，不诱发「再规划一轮」。

---

## 6. 非目标（本专题不做）

- 不自动根据天数/完成度推进阶段（阶段切换保持手动）。  
- 不做精巧的练习/应用教研大纲或九宫格（三阶段 × 三类活动全量常驻编辑）。  
- 不在本专题重做完整 PDCA 四栏或真实后端。  
- 不规定练习/应用共创是否必须复用「对话共创」壳（可另开提示词）。

---

## 7. 结论

| 项 | 结论 |
|----|------|
| 计划 | 一份主题计划；阶段切换 = 归档 + 新生成 |
| 阶段 | 手切；默认比重不同；可手改；练/用不精巧 |
| 完成 | 阶段完成 ≠ 主题毕业 |
| 并发 | 硬拦 1 学 + 3 练 + 5 用 |
| 主焦点 | 手设 ≤3；>1 强警告 + 记漂移 |
| 下一阶段 | 设计说明已配套；可用 Trae 提示词做高保真 |
