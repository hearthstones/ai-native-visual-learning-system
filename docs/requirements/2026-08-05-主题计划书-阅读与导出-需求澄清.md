## 1. 本专题解决什么

冷启动共创已产出阶梯 / 资料 / 计划三份活文档，但锁定后缺少稳定的**通读入口**；同时轻量用户需要能把计划**带走**（HTML）。

本专题定案：

1. **主题计划书**：站内只读视图，聚合阶梯 + 资料 + 计划；  
2. **HTML 导出**：与站内阅读共用同一内容结构；  
3. **明确不含**：今日任务、复盘正文。

---

## 2. 决策结论

### 2.1 内容范围

| 包含 | 不含 |
|------|------|
| 学习阶梯（含当前选定级别） | 今日任务 / 切片勾选 |
| 学习资料清单 | 复盘正文与周复盘表单 |
| 学习计划（学/练/用完整 phases） | 阶段槽位管理、主焦点操作 |

复盘可在页面底部留**弱链**指向现有复盘入口，不进入计划书本体。

### 2.2 数据真源

| 块 | 真源 |
|----|------|
| 阶梯 | `Theme.ladder_doc` + `current_ladder_level` |
| 资料 | `Theme.resources_doc` |
| 计划 | 学习期 `PlanSlice.doc`（完整 plan_doc，非当前 active-slice 的截断 doc） |

### 2.3 入口与边界

- **挂载**：L2 主题看板次要导航「主题计划书」；不取代「进入执行」。  
- **与「调整计划」分开**：计划书 = 读共创产物；调整计划 = 阶段 / 槽位 / 再共创。  
- **路由**：`/themes/:themeId/document`（不占用已有 `/plan`）。  
- **可用性**：计划锁定后完整可用；未锁定时引导继续共创。

### 2.4 导出（本轮）

- **形态**：HTML（单文件，可离线打开）。  
- **时机**：锁定后可导出。  
- **内容**：与站内计划书一致（阶梯 + 资料 + 计划）。  
- **视觉**：与站内阅读页同一套 Trae 深色风格（tokens / 阶梯卡 / 资料卡 / 会话卡），不另起浅色文档皮肤。  
- **本轮不做**：Markdown / PDF、页内勾选改期、独立轻量入口（不建主题只导出）。

---

## 3. 明确不做

- 不把复盘正文并入计划书。  
- 不推翻 L1 / L2 / L3 主路径。  
- 不把计划书做成第二个作业台。

---

## 4. 一句话

主题计划书 = 锁定后的共创交付物（阶梯 · 资料 · 计划）；站内通读，HTML 带走；任务与复盘各走原入口。
