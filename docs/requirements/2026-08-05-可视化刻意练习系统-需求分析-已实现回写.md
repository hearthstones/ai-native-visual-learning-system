## 2. 产品定义

### 2.1 一句话

以「主题」为基本单位，覆盖 **计划 → 执行 → 检查 → 改进（PDCA）** 的可视化刻意练习工作台；**AI 承担大部分计划与复盘，用户聚焦执行**。

### 2.2 产品身份

| 是 | 不是 |
|----|------|
| 主题级 PDCA 工作台 | 第二大脑 / 巨型知识图谱 |
| 刻意练习执行器（今日任务 + 阶段演进） | 通用笔记仓库 |
| AI 共创驱动的计划生成与周复盘 | Freedom Engine / LLM Wiki 替代品 |
| 单人网页应用（可服务器部署） | 多租户 / 协作学习平台 |

### 2.3 品牌与壳层文案

界面壳层品牌信号为「刻意练习」；仓库/工程名称为 AI Native Visual Learning System（可视化刻意练习系统）。

### 2.4 领域与用途

| 维度 | 内容 |
|------|------|
| **领域类型** | `general` 通识 · `tech` 技术（共用同一主题工作台壳） |
| **通识主要输入** | 资料共创中可约束/enrich 微信读书书目 |
| **技术主要输入** | 同一资料共创壳；材料形态不绑死单一来源 |
| **用途** | ① 学新技术 / 专题 ② 对约 20% 核心做刻意练习与应用 |

锚定验证主题（产品叙事）：「革新学习方法」类真实主题阅读。

## 3. 背景与痛点（需求动机）

按 PDCA 归纳的原始痛点，已转化为系统职责分工：

| 阶段 | 痛点 | 系统应对（已实现） |
|------|------|-------------------|
| **P 计划过度** | 规划挤占执行 | 三次 AI 共创（阶梯 / 资料 / 计划）+ 锁定；用户确认而非从零写计划 |
| **D 执行不足 / 漂移** | 易新开主题、注意力摊薄 | 阶段槽位硬拦 1+3+5；主焦点 ≤3；满槽新建拦截；今日任务配额 |
| **C/A 复盘成本高** | 有用但难坚持 | 周复盘：掌握度 + 三问 → AI 输出 summary / wins / issues / adjustments |

## 4. 目标与非目标

### 4.1 目标（本版本）

1. 用户能以**主题**跑通完整 PDCA：创建共创锁定 → 今日执行 → 阶段管理 → 周复盘。  
2. AI 完成大部分 P 与 C/A；用户主要完成 D。  
3. 可视化呈现：今日任务、主题进度、槽位占用、主焦点与漂移提示、共创活文档、计划书。  
4. 通识与技术共用主题壳；通识侧可对接微信读书搜索 enrichment。  
5. 网页可本地或服务器稳定自用；数据落 SQLite。  
6. 锁定后的共创产物可站内通读为**主题计划书**（阶梯 · 资料 · 计划三章），并以 **HTML 单文件**（同构深色风格）带走。

### 4.2 非目标（本版本明确不做）

- 多用户账号体系、RBAC、分享协作（**已有**可选单账号门禁，见 §5；非多租户）。  
- 第二大脑、跨主题知识图谱、与 LLM Wiki 等外部知识资产深度合并。  
- 以产出/收入为主指标的商业化闭环。  
- 「研究模式 / 阅读模式」两套 UI 引擎。  
- Markdown / PDF 导出；计划导入；独立「不建主题只导出」轻量入口。  
- 微信读书划线/笔记本全量导入产品化（Skill 仓库有能力文档，主路径未接）。  
- **通用 / 联网搜索**（资料共创未接；外部资料目前仅微信读书 enrichment，其余依赖模型预训练；2026-08-11 记账见体验反馈 §1.1；**2026-08-12 升格为产品身份问题并定案暂停**，见 [诚实记账与暂停](./2026-08-12-能力边界与产品身份-诚实记账与暂停.md)）。  
- Electron 桌面壳（技术选型预留，未实现）。  

> **已落地、勿再列入非目标**：共创 SSE 流式打字（`/cocreate/start/stream`、`/{kind}/message/stream`）；可选单账号登录门禁（`AUTH_PASSWORD`）。

### 4.3 成功标准（需求层，可验收）

在真实主题上，若以下成立则方向验证通过：

1. **计划负担下降**：用户很少从零写计划，主要确认 AI 活文档并锁定。  
2. **执行更稳**：同一主题可持续推进；新开主题受槽位与拦截约束，漂移可被看见。  
3. **复盘可负担**：周复盘以短表单 + AI 结果完成，产出可执行调整建议。  
4. **刻意练习可见**：计划含约 20% 核心；今日任务与活动勾选可追踪。  
5. **计划可带走**：锁定后可通读主题计划书并导出 HTML。

## 6. 信息架构（三层）

系统主界面按三层组织，禁止回流为「PDCA 四栏等权常驻工作台」。

| 层级 | 路由 | 回答的问题 | 有什么 | 刻意没有什么 |
|------|------|------------|--------|--------------|
| **L1 今天** | `/` | 今天干什么 / 进哪个主题 | 跨主题今日任务、主题卡（最多展示 4）、槽位摘要、漂移提示、新建入口 | 完整共创、完整阶段台、完整周复盘表单 |
| **L2 主题看板** | `/themes/:id` | 这个主题整体怎样、下一步 | 阶段/进度摘要、核心概念摘要、进入执行主 CTA、次要导航（计划书/阶段/作业等） | 完整共创对话、完整复盘表单 |
| **L3 作业面** | `/themes/:id/work?mode=` | 当前专注一种操作 | `execute` / `plan` / `review` 三模式；执行主区；模式子入口 | 四栏等权、他模式完整内容常驻 |

**壳层导航**（Activity Rail / 移动端 Tab）：今天 · 主题 · 复盘 · 设置。  
**全屏无壳**：冷启动共创、满槽拦截等创建向页面。

| 路由 | 职责 |
|------|------|

## 7. 核心领域概念

### 7.1 两套「阶段」不得混名

| 用语 | 含义 | 出现位置 |
|------|------|----------|
| **学习阶梯级别** | 能力台阶 L1–L5；用户点选「我现在在哪」 | 冷启动阶梯共创；写入 `current_ladder_level` |
| **主题生命周期阶段（phase）** | `learning` → `practice` → `application`；手动推进 | 计划结构、槽位、阶段管理页 |

### 7.2 实体字典

| 实体 | 含义 | 关键字段/结构 |
|------|------|----------------|
| **Theme** | 学习主题 | title, theme_type, goal, phase, status, is_focus, ladder_doc, resources_doc, current_ladder_level, locked_at, previous_status |
| **PlanSlice** | 某主题某 phase 的计划切片 | slice_status: draft/active/completed；doc 存完整 plan_doc |
| **Activity** | 切片内活动 | learn/practice/apply；done；与 DailyTask 可同步 |
| **DailyTask** | 某日推进任务 | task_date；通常挂 activity；每主题每日最多取 2 条未完成活动生成 |
| **CocreateSession** | 共创会话 | kind: stage/resources/plan；messages；live_doc；confirmed |
| **DriftEvent** | 计划漂移事件 | 如主焦点 >1 时记录 |
| **WeeklyReview** | 周复盘结果 | summary, wins, issues, adjustments, raw |
| **Slot** | 阶段并发容量（派生） | 学 1 / 练 3 / 用 5；仅计 `status=active` |
| **Focus** | 主焦点（派生+字段） | `is_focus`；上限 3 |

### 7.3 计划文档结构（plan_doc，JSON）

计划共创确认后的活文档典型包含：

- `goal`：目标陈述  
- `core_20`：约 20% 核心要点  
- `durations` / 节奏偏好  
- `phases.learning|practice|application`：各阶段标题与 `activities[]`  

锁定时：以**学习期 activities** 生成 active 切片与 Activity；练习/应用期可建 draft 骨架切片，待推进时激活。

### 7.4 阶梯 / 资料活文档

| 文档 | 职责 |
|------|------|
| `ladder_doc` | 五级台阶描述；用户确认当前级 |
| `resources_doc` | 高杠杆资料清单、排序、短路径、约束；可含微信读书 enrichment |

## 8. 功能需求（按模块）

### 8.1 主题生命周期

**FR-T1 主题类型与创建**  
系统应支持创建主题，必填主题名、类型（通识/技术），可选一句话目标；创建后状态为 `draft`，未锁定前不占学习槽的「可执行」语义（锁定后才 `active`）。

**FR-T2 七态状态机**  

| 状态 | 含义 | 主要规则 |
|------|------|----------|
| `draft` | 草稿 | 须计划锁定后才能变 active |
| `active` | 进行中 | 占用对应 phase 槽位；可有今日任务与主焦点 |
| `dormant` | 休眠 | 释放槽位与焦点；清今日任务 |
| `completed` | 毕业 | **仅应用期**可标记完成 |
| `abandoned` | 废弃 | 释放槽位 |
| `archived` | 归档 | 保留 `previous_status` 供恢复 |
| `deleted` | 回收站（软删） | 可恢复；永久删除仅允许自回收站 purge |

**FR-T3 主题管理页**  
`/themes` 应提供主 Tab（进行/草稿/休眠/完成）与历史（废弃/归档/回收站）；支持编辑标题/目标、设/取消主焦点、状态操作与恢复。

**FR-T4 阶段推进**  
用户可手动将主题从学习 → 练习 → 应用；推进时校验下一阶段槽位；当前 active 切片标 completed；激活下一阶段 draft 切片（若无则生成骨架）；重生今日任务。不根据天数/完成度自动推进。

### 8.2 并发：阶段槽位与主焦点

**FR-C1 阶段槽位（硬拦）**  

| 阶段 | 同时 active 上限 |
|------|------------------|
| 学习 | 1 |
| 练习 | 3 |
| 应用 | 5 |

触顶时不可再锁定落入该阶段、不可再推进到该阶段，除非先推进/休眠/废弃腾槽。锁定计划时须校验学习槽（再锁定时排除本主题自身占用）。

**FR-C2 主焦点**  
- 手设；仅 active 主题计入；上限 **3**（硬顶）。  
- =1：正常。  
- >1 且 ≤3：允许，**强警告 + 写入 DriftEvent**。  
- 计划锁定时若尚未设焦点，默认设为焦点。

**FR-C3 漂移可见**  
L1（及管理相关表面）应能展示漂移提示，使「注意力摊薄」可被事后看见。

**FR-C4 满槽新建拦截**  
学习槽已满时，从新建入口进入拦截页，展示占用主题进度，提供三选一：推进到练习期 / 休眠 / 废弃；腾槽后方可继续创建。学习槽空闲时不得默认进入该拦截。

### 8.3 冷启动与三次 AI 共创

**FR-S1 主路径（硬约束）**

```text
① 主题信息（唯一表单）
② 学习阶梯 AI 共创 → 用户确认当前级别
③ 学习资料 AI 共创 → 多轮约束/评估/否决
④ 学习计划 AI 共创 → 显式锁定
→ 计划已锁定着陆 → L2 / L3 可执行
```

**FR-S2 共创交互壳**  
②③④ 必须为**左对话 / 右活文档**；禁止做成纯表单关卡或「来源单选 → 导入占位 → 核心预览」流水线。

**FR-S3 确认与重开**  
每步确认后写回主题文档；支持重新共创（计划支持 `force` / `revise=1`）；再锁定计划时清除旧切片/活动/任务后重建。

**FR-S4 锁定语义**  
- 锁定前：今日任务不生效。  
- 锁定后：`status=active`，`phase=learning`，生成学习期 active 切片与活动，生成今日任务，默认主焦点，写入 `locked_at`。  
- 锁定前若学习槽满：阻塞并引导腾槽。

**FR-S5 Skill 映射**  

| 步骤 | Skill | 产品职责 |
|------|-------|----------|
| 阶梯 | `ai-learning-step1-stage` | 拆台阶 + 用户确认当前级 |
| 资料 | `ai-learning-step2-resource` | 高杠杆清单；可微信读书 enrich |
| 计划 | `ai-learning-step3-plan` 精神 | 约 20% 核心 + 学/练/用三阶段；节奏偏向可执行（约 30 分钟/天量级叙事） |

**FR-S6 AI 输出契约**  
共创接口须返回可解析的 `{ assistant_message, live_doc }`；失败允许有限次重试。

**FR-S7 否决回流**  
实现与验收不得回流到：材料来源表单流水线；把三共创塞进一页问卷；空槽用户强制满槽拦截；锁定后 Day1 任务与计划切片叙事不一致；仅用静态剧本却声称已完成真实定制（演示除外，成功标准仍要求可注入约束并更新文档）。

### 8.4 学习执行（Do）

**FR-D1 今日任务生成**  
对每个 active 主题，从当前 active 切片取最多 **2** 条未完成活动，生成本日 DailyTask；标题应语义化为「今日可完成」短句。

**FR-D2 勾选同步**  
勾选 DailyTask 应可同步对应 Activity.done；反向在阶段管理勾选活动时保持一致语义。

**FR-D3 L3 执行模式**  
应提供任务列表、切片进度、材料提示；支持本地笔记（localStorage）；可将笔记草稿带入周复盘（`weekly-review-draft`）。

**FR-D4 L1 聚合**  
首页聚合跨主题今日任务与主题卡；主题卡展示有上限策略（当前实现截断约 4 张并链到主题列表）。

### 8.5 计划调整与阶段管理

**FR-P1 阶段管理页**（`/themes/:id/plan`）应支持：  
- 学→练→用步进与确认（低完成度可二次确认）；  
- 槽位占用可视化与下一阶段满槽拦截；  
- 主焦点开关与多焦点警告；  
- 切片内活动勾选；  
- 应用期标记完成等与状态机一致的操作；  
- 链到计划再共创（`/create/:id/plan?revise=1`）。

**FR-P2 与计划书分工**  
「调整计划 / 阶段管理」负责阶段、槽位、再共创；「主题计划书」只读共创交付物，不做作业台。

### 8.6 主题计划书与导出

> 专题定案见 [2026-08-05 主题计划书 · 阅读与导出](./2026-08-05-主题计划书-阅读与导出-需求澄清.md)；灵感见 [2026-08-04 学习计划导出](./2026-08-04-学习计划导出-需求澄清.md)。  
> **一句话**：主题计划书 = 锁定后的共创交付物（阶梯 · 资料 · 计划）；站内通读，HTML 带走；任务与复盘各走原入口。

#### 8.6.1 要解决什么问题

冷启动三次共创已产出阶梯 / 资料 / 计划三份活文档，但锁定后缺少稳定的**通读入口**；同时存在「一次性带走计划」的轻量需求（HTML 离线可读）。本能力提供：

1. **站内只读计划书**：聚合三份共创产物，可通读；  
2. **HTML 单文件导出**：与站内同一内容结构与深色视觉，可离线打开；  
3. **明确边界**：不含今日任务与复盘正文；不替代执行台或阶段管理台。

#### 8.6.2 内容范围与数据真源

| 章 | 包含 | 数据真源 |
|----|------|----------|
| 一、学习阶梯 | 五级台阶；高亮当前选定级别（「当前定位」） | `Theme.ladder_doc` + `current_ladder_level` |
| 二、学习资料 | 约束标签、rationale、7 日路径、资源卡（适合/难度/覆盖/为何选/最短路径/注意等） | `Theme.resources_doc` |
| 三、学习计划 | 目标、rationale、每日分钟建议、核心精神（`core_20`）、学/练/用完整 phases 与活动会话 | 学习期 `PlanSlice.doc` 完整 `plan_doc`（**非**当前 active-slice 截断） |

| 明确不含 | 说明 |
|----------|------|
| 今日任务 / 切片勾选态 | 执行态，不进计划书 |
| 复盘正文与周复盘表单 | 底部可弱链到 `/review`，不进本体 |
| 阶段槽位管理、主焦点操作 | 属「调整计划」`/themes/:id/plan` |

#### 8.6.3 入口、路由与职责边界

| 项 | 要求 |
|----|------|
| **路由** | `/themes/:themeId/document`（不占用已有 `/plan`） |
| **主入口** | L2 主题看板次要导航「主题计划书」；**不取代**「进入执行」主 CTA |
| **次入口** | 锁定着陆页「查看主题计划书」；练习期看板变体亦可链入 |
| **壳层标题** | Activity Rail / 顶栏在该路由显示「主题计划书」 |
| **与调整计划分开** | 计划书 = **读**共创产物；调整计划 = 阶段 / 槽位 / 再共创 |
| **可用性** | 锁定后完整通读与导出；未锁定时展示引导，链到草稿续共创路径（`draftResumePath`） |

#### 8.6.4 站内阅读页（已实现交互规格）

**FR-E1 页面结构（docbook）**  
页面应为「计划书」阅读壳，而非共创左右分栏：

1. **工具栏**：返回主题看板；「导出 HTML」按钮（未锁定或三章皆空时禁用，`title` 提示「锁定计划后可导出」）。  
2. **页眉**：眉题「主题计划书」；主题标题；阶段标签 + 可选目标；未锁定时「未锁定」标签。  
3. **未锁定空态**：文案引导完成共创并锁定；主按钮跳转续共创。  
4. **目录（TOC）**：锚点链到三章——「一、学习阶梯」「二、学习资料」「三、学习计划」。  
5. **正文三章**：章序号 01 / 02 / 03；各章无内容时显示空态文案。  
6. **页脚弱链**：注明「不含今日任务与复盘」；链到「调整计划」「周复盘」「进入执行」。

**FR-E2 组件复用**  
三章应复用共创右侧活文档组件的**只读 / embedded** 形态，保证与共创确认所见一致：

- 阶梯：`StageDoc`（`readOnly` + `embedded`，不可点选改级）  
- 资料：`ResourcesDoc`（`embedded`）  
- 计划：`PlanDoc`（`embedded`，`showReadyCard=false`，弱化共创分区序号）

样式：`theme-document.css` + 共创相关样式；视觉为 Trae 深色 tokens。

#### 8.6.5 HTML 导出（已实现规格）

**FR-E3 导出形态与时机**

| 项 | 要求 |
|----|------|
| 形态 | **单文件 HTML**（内联样式），浏览器可离线打开 |
| 时机 | 主题**已锁定**，且阶梯 / 资料 / 计划至少一块有内容 |
| 内容 | 与站内三章结构一致（目录 + 阶梯 + 资料 + 计划） |
| 视觉 | **同一套 Trae 深色风格**（tokens、阶梯行、资料卡、会话卡、核心精神列表）；不另起浅色「打印文档」皮肤 |
| 文件名 | `{主题名}-计划书.html`（非法文件名字符替换） |
| 实现位置 | 前端生成下载（`exportPlanDocumentHtml`），不依赖服务端渲染文件 |

**FR-E4 导出内容细节（与站内对齐）**

- **阶梯**：L1–L5 行；当前级别徽章「当前定位」；理解/掌握/核心概念/里程碑/练习/自检等非空字段。  
- **资料**：过滤掉「主题/类型/目标/当前阶梯」类元约束展示；资源类型/难度中文化；前两条可标「核心」。  
- **计划**：目标与 rationale；练/用期每日分钟建议；「核心精神」列表；学/练/用 phase 块（时长徽章 + 活动会话卡：序号、标题、时长、说明）。

**FR-E5 本轮明确不做（导出相关）**

- Markdown / PDF / 纯文本导出  
- 导出页内勾选、改期、可编辑  
- 独立轻量入口（不建主题、不进看板，只共创并导出）  
- 把导出做成独立产品线或营销页

#### 8.6.6 与主路径的关系及否决

- 不推翻 L1 / L2 / L3 主路径；计划书是锁定后的**交付物出口**，不是第二作业台。  
- 不把复盘正文并入计划书。  
- 承认「突然想学 → 带走一份计划」的轻量心智，但本版本出口挂在主题计划书上，**不开**「无主题旁路」。

### 8.7 周复盘（Check / Act）

**FR-R1 输入**  
- 选定焦点主题（查询参数 / 主焦点 / 首个 active 等回退策略）；  
- 核心概念掌握度 1–5；  
- 三问草稿：应用场景、薄弱点、调整意向；  
- 草稿可存 localStorage。

**FR-R2 输出**  
AI 生成并落库：`summary`、`wins`、`issues`、`adjustments`；可展示最近一次结果。

**FR-R3 入口**  
壳层「复盘」与 L3 review 模式入口指向周复盘能力。

### 8.8 设置与外部集成

**FR-CFG1** 可配置 DeepSeek：API Key、Base URL、Model（含自定义）；密钥掩码展示；写入根 `.env` 后即时生效。  
**FR-CFG2** 可配置微信读书 API Key；资料共创后可按书名 hint 搜索 enrichment；提供 `GET /api/weread/search`。  
**FR-CFG3** 提供 LLM 连通测试与健康检查（含密钥是否配置）。

### 8.9 AI 能力一览

| 能力 | 触发 | 说明 |
|------|------|------|
| 阶梯共创 | cocreate start/message | Skill1 |
| 资料共创 | cocreate start/message | Skill2 + 可选 Weread |
| 计划共创 | cocreate start/message | Skill3 改编 |
| 周复盘 | POST `/reviews/weekly` | 内联系统提示 |
| 设置测试 | POST `/settings/test-llm` | 短 echo |

## 9. 关键用户流程

### 9.1 冷启动到可执行

1. L1 空态「新建第一个主题」（槽满则进拦截）。  
2. 填写主题信息 → 创建 draft。  
3. 阶梯共创 → 选级 → 确认 → 写 `ladder_doc`。  
4. 资料共创 → 多轮 → 确认 → 写 `resources_doc`（可 Weread）。  
5. 计划共创 → 调节奏 → 锁定计划 → active + 学习切片 + 今日任务 + 默认焦点。  
6. `/summary` → 进入看板或作业面。

### 9.2 日常执行

1. L1 勾选今日任务，或经主题卡进入 L2。  
2. L2「进入执行」→ L3 execute。  
3. 勾选完成；可选本地笔记 → 带到周复盘。

### 9.3 阶段演进

1. 拦截页或阶段管理页发起推进。  
2. 校验下一阶段槽位 → 归档当前切片 → 激活下一阶段 → 重生今日任务。

### 9.4 再共创计划

作业面/阶段页 → `/create/:id/plan?revise=1` → force 重开会话 → 再锁定（purge 后重建）。

### 9.5 周复盘

填写掌握度与三问 → 提交 AI 生成 → 落库展示。

### 9.6 计划书通读与带走

1. 锁定后从 L2（或锁定着陆页）进入「主题计划书」。  
2. 经目录浏览三章：阶梯 → 资料 → 计划（只读，与共创活文档同构）。  
3. 可选：页脚弱链去调整计划 / 周复盘 / 进入执行。  
4. 点击「导出 HTML」→ 下载单文件深色风格计划书，离线打开内容与站内一致。

## 10. 接口需求（API 契约摘要）

前缀：`/api`。未设 `AUTH_PASSWORD` 时无门禁；启用后门禁保护业务路由（`/health`、`/api/auth/*` 例外见实现）。

### 10.1 Home / 全局

| 方法 | 路径 | 需求 |

| GET | `/slots` | 学/练/用 used/max |
| PATCH | `/tasks/{task_id}` | 今日任务完成态；可同步 Activity |
| POST | `/reviews/weekly` | 生成并落库周复盘 |
| GET | `/reviews/weekly/latest` | 最近一次周复盘 |
| GET | `/weread/search?q=` | 微信读书搜书 |
| GET | `/health` | 健康检查 |

### 10.2 Themes

| 方法 | 路径 | 需求 |
|------|------|------|
| GET | `/themes?status=` | 列表过滤 |
| POST | `/themes` | 创建草稿 |
| GET/PATCH | `/themes/{id}` | 详情 / 更新 |
| POST | `/themes/{id}/restore` | 自回收站或归档恢复 |
| DELETE | `/themes/{id}` | 永久删除（仅回收站） |

## 14. 弱实现、残留与相对澄清文档的差异

| 项 | 现状 | 说明 |
|----|------|------|
| `ThemePracticePage` | 路由存在 | 主路径几乎不链入；练习期看板变体残留 |
| SSE 流式共创 | 已接 | `assistant_message` 流式打字；`live_doc` 结束后刷新 |
| L1 主题卡 >4 | 粗截断 | `slice(0,4)` +「查看全部」；动态策略仍粗 |
| 掌握度可视化 | 部分 | 评分在周复盘；L2「本周自评」不写回持久掌握度字段 |
| 作业笔记 | localStorage + `Theme.work_note` | 服务端已持久化；本机缓存仍作草稿辅助 |
| Weread 深度能力 | 仅 search/enrich | 划线/笔记本未产品化 |
| 练习/应用期计划精修 | 骨架为主 | 冷启动可给骨架；再共创主要在计划 revise；不追求精巧大纲 |
| 任务完成判定细则 | 勾选即完成 | 未做题型判定、应用结构化模板等 |
| 独立轻量「只导出」入口 | 未做 | 导出挂在主题计划书；轻量心智见 08-04 灵感，08-05 定案未开旁路 |
| 多用户 / RBAC | 未做 | 仅可选单账号门禁；非多租户 |

早期澄清中仍「开放」但实现已给出默认答案的项：

- 网页 IA → **已定 L1/L2/L3**。  
- 创建路径 → **信息 + 三共创**（否决 v1 表单四步）。  
- 并发 → **1+3+5 + 主焦点**。  
- 导出 → **锁定后 HTML，含阶梯+资料+计划**。

仍真正后置、未在本版本承诺的项：应用记录最小字段模板、每日配额精细策略、技术材料对称导入器、多格式导出、多用户 / RBAC。

## 15. 明确否决项（防回流）

1. ❌ 创建主路径：材料来源单选 → 导入占位 → 核心预览表单。  
2. ❌ 把阶梯/资料/计划塞进同一页问卷一次性填完。  
3. ❌ 空槽用户默认进入「先腾学习槽」拦截。  
4. ❌ 任何未毕业主题都禁止新开学习（应以槽位规则为准）。  
5. ❌ 自动按天数推进阶段。  
6. ❌ 计划书并入今日任务与复盘正文，或做成第二个作业台。  
7. ❌ 因导出灵感推翻主题/阶段/看板主路径。  
8. ❌ 本阶段做第二大脑或跨主题巨型图谱。
