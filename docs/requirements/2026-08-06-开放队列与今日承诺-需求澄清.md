# 开放队列 + 今日承诺 · 需求澄清

> 状态：定案，进入实现  
> 日期：2026-08-06  
> 背景：任务与日期强挂钩制造内疚；滴答 + GTD 经验支持「队列无日期、今天靠承诺」

---

## 1. 定案

采用 **B. 开放队列 + 今日承诺**：

| 层 | 含义 |
|----|------|
| **可做队列** | 各进行中主题 · 当前切片里**未完成**的 Activity；不带日期、不标逾期 |
| **今日承诺** | 用户显式「加入今天」后写入的 `DailyTask(task_date=今天)` |
| **没做完** | Activity 仍留在队列；昨日承诺仅作复盘统计，**不**渲染为失败/逾期 |

## 2. 规则（V1）

1. **首页不再静默灌今日任务**（取消每天自动取前 2 条）。  
2. 每主题每日承诺上限仍为 **2**。  
3. 提供「按建议填入」：从该主题队列按顺序补满至上限（显式动作，非静默）。  
4. 可「移出今天」：删除当日 `DailyTask`，不改 Activity.done。  
5. 锁定计划 / 阶段推进 / 恢复进行中：**不**自动生成今日承诺。  
6. `task_date` 保留，供周复盘统计。

## 3. 首页信息架构

```text
今日承诺（已加入今天的）
  → 勾选完成 / 进入 / 移出今天
可做队列（未承诺的未完成活动）
  → 加入今天 · 按建议填入（每主题）
```

## 4. 明确不做（本轮）

- 不引入第二套独立 Inbox 实体（队列真源仍是 Activity）。  
- 不做跨日「逾期」标签。  
- 不按时长预算自动装载（D 方案后置）。
