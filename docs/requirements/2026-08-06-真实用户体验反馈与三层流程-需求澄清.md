## 1. 真实反馈原文（原意保留）

以下三条为用户原意转述，讨论与实现均以此为准，不稀释：

1. **资料收集阶段，资料过于官方，特别是技术主题。**
2. **资料收集阶段，很多时候用户甚至不需要原始资料，而是需要 AI 加工后的资料。**
3. **L1、L2、L3 功能有重叠的地方，跳来跳去太耗费用户心智。**

### 1.1 能力缺口补记（2026-08-11）

**系统未接入通用/联网搜索。** 资料共创阶段模型可用的外部资料源目前只有：

1. **微信读书**（书目搜索 enrichment）  
2. **模型预训练内容**（无实时检索）

因此清单易偏「书单 / 官方教材感」，尤其技术主题缺少文档、博客、课程、开源仓库等活水源。本条作为反馈①的根因记账，归入后续资料策展专题，本轮不定案、不改代码。

## 4. 定案：今日看板 + 主题看板

对齐滴答清单，**两面**，不对等第三层。

```text
今日看板（侧重任务） ←→ 主题看板（侧重主题）
```

| 表面 | 侧重 | 职责 | 与现状关系 |
|------|------|------|------------|
| **今日看板** | 任务 | 今日承诺 + 快捷选择（可做队列）、主题轻度展示 + 快捷入口、槽位等 | **基本维持**；与开放队列 + 今日承诺一致 |
| **主题看板** | 主题 | 主题管理与详情：信息、计划管理、**任务执行**、复盘改进 | **吸收旧 L2 + L3**；取消独立作业面作为日常主路径 |

### 4.1 今日看板（维持）

- 回答：**今天干什么 / 从队列拉什么进今天 / 进哪个主题。**  
- 有：今日承诺、可做队列（加入今天 / 按建议填入）、主题轻量卡、槽位与漂移提示、新建入口。  
- 没有：完整共创、完整阶段台、完整复盘表单、主题内计划编辑。  
- 与 [开放队列 + 今日承诺](./2026-08-06-开放队列与今日承诺-需求澄清.md) 对齐，不另起任务模型。

### 4.2 主题看板（加重）

同一主题下的多职责容器；用户心智是「还在这个主题里」，不是「又进了一层作业 App」。

| 区块 | 职责 |
|------|------|
| **主题信息** | 阶段、阶梯摘要、漂移等只读/轻交互 |
| **计划管理** | 计划书、阶段、共创/修订入口 |
| **任务执行** | 可做 / 今日相关任务的勾选与展开（旧 L3 execute 迁入） |
| **复盘改进** | 周复盘与改进入口（旧 L3 review / 壳层复盘入口收束到此） |

实现形态（同页分区 / 子 Tab / 锚点）属交互保真度，需求只约束：**不拆出与今日/主题对等的第三日常表面。**

### 4.3 今日任务点击着陆（B）

- 今日看板上对任务 **就地完成**（勾选不跳转）；日常「做事」尽量留在今日。  
- **仅**点击「进入主题」/ 主题轻卡 → 进入**主题看板**（主题管理、计划、该主题任务执行、复盘等）。  
- 否决：点今日任务默认跳进主题看板或独立作业面（旧 L3）。  
- 主题看板仍保留任务执行区，供在主题语境下查看/操作该主题任务；**不**作为今日任务的默认着陆。

### 4.4 日常主路径

```text
打开 App → 今日看板
  → 承诺/队列操作 + 今日任务就地勾选完成（留在今日）
  → 需要主题语境时：点主题入口 → 主题看板（信息/计划/执行/复盘）
  → 计划管理 / 复盘改进 / 计划书：均从主题看板进入（可进子页，返回主题看板）
  → Rail / 返回「今天」→ 今日看板
```

冷启动锁定后第一落点：**今日看板**；**不**再默认「先看摘要再进作业面」。

### 4.5 入口唯一性

| 能力 | 唯一主入口 |
|------|------------|
| 今日承诺 / 可做队列 | 今日看板 |
| 今日任务完成（日常） | 今日看板 · **就地勾选**（着陆 B） |
| 任务执行（主题语境） | 主题看板 · 任务执行区（经主题入口进入） |
| 计划管理 / 共创修订 | 主题看板 · 计划管理 |
| 主题计划书 | 主题看板 · 计划管理（次要出口） |
| 复盘改进 | 主题看板 · 复盘改进 |
| 壳层「复盘」等 | 可保留快捷，但须落到主题看板复盘区块或同一复盘子页，不另造第三套作业壳 |

## 5. 明确否决

- 否决「今日 → 主题摘要 → 独立作业面」必经链。  
- 否决独立作业面作为与今日/主题对等的第三层（旧 L3 `ThemeWorkPage` / `/themes/:id/work` 的主路径角色）。  
- 否决点今日任务默认跳进主题看板或作业面（着陆 A）；日常完成以就地勾选为准（着陆 B）。  
- 否决继续用「L1/L2/L3」作为需求主叙事（迁移对照除外）。  
- 本轮不改资料 Skill / 共创交付物（反馈①②仅记账）。  
- 本轮需求定案**不改代码**；实现见后续迭代。

## 6. 迁移对照（旧 → 新）

| 旧 | 新 |
|----|----|
| L1 今天 | **今日看板**（职责基本不变） |
| L2 主题看板（偏摘要 +「进入执行」） | **主题看板**（信息 + 计划 + **执行** + 复盘） |
| L3 作业面 execute / plan / review | 能力迁入主题看板对应区块；路由可暂时保留但退出主路径 |
| L1 任务 → L3 | 今日任务 **就地完成**（着陆 B）；不默认进主题/作业面 |
| L2「进入执行」主 CTA | 取消「再进一层」；主题入口进主题看板（含执行区） |

实现影响预览（非本轮范围）：

- 弱化主路径：`ThemeWorkPage`、`/themes/:id/work`  
- 加重：`ThemeOverviewPage`（执行区迁入，经主题入口到达）  
- 今日侧：`HomePage` 强化就地勾选；任务行不默认跳转主题看板
