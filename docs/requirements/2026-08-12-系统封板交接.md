## 2. 系统停在什么状态

**一句话**：单人网页版可视化刻意练习工作台；AI 共创生成阶梯 / 资料 / 计划，用户靠开放队列 + 今日承诺执行，槽位约束学练用并发。

**主路径（可验收）**：

```text
空首页 → 创建主题信息 → 阶梯共创 → 资料共创 → 计划共创锁定
→ 锁定着陆 → 今日看板 / 主题看板 → 今日承诺执行 / 任务拆分
→ 阶段管理（1+3+5）→ 周复盘 → 主题计划书通读 · 导出 HTML
```

**暂停前最后落地（相对早期回写）**：共创 SSE；可选单账号门禁；开放队列 + 今日承诺；功能清单 2026-08-12 整表回写。

## 5. 本地自用（不视为恢复产品开发）

1. 根目录 `.env`：参考 `.env.example`（`DEEPSEEK_*`、`WEREAD_API_KEY`、可选 `AUTH_*`）。  
2. API：`cd apps/api && uv sync && uv run uvicorn app.main:app --reload --port 8000`  
3. Web：`cd apps/web && npm install && npm run dev` → http://localhost:5173  
4. 数据：`data/learning.db`（**不进 git**；有价值请自行仓外备份）。  
5. 部署参照：`deploy/nginx-host.conf`、`deploy/learning-api.service`。
