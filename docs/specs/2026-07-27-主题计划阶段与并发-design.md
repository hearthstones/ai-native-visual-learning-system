## 1. 目标

把「一份计划 + 三阶段演进 + 全局并发硬拦 + 主焦点漂移」落成可实现的产品规则与界面职责，供原型与后续实现共用。

---

## 2. 核心对象

### 2.1 Theme（主题）

| 字段（逻辑） | 说明 |
|--------------|------|
| `id` / `title` | 主题标识与名称 |
| `phase` | `learning` \| `practice` \| `application`（当前阶段） |
| `status` | `active` \| `dormant` \| `archived`（休眠/废弃释放槽位） |
| `is_focus` | 是否主焦点（布尔） |
| `plan_timeline` | 按阶段切片的计划时间线（见下） |

### 2.2 Plan slice（计划切片）

每个主题在生命周期中最多有三段切片（可尚未生成）：

| `phase` | 用户可见名 | 生成时机 |
|---------|------------|----------|
| learning | 学习计划 | 主题进入学习期（创建时默认） |
| practice | 练习计划 | 用户确认进入练习期时**新生成** |
| application | 应用计划 | 用户确认进入应用期时**新生成** |

切片状态：

| `slice_status` | 含义 |
|----------------|------|
| `draft` | 共创/编辑中，未锁定 |
| `active` | 当前阶段正在执行的计划 |
| `completed` | 已随阶段切换归档，**只读** |

规则：

- 任意时刻，**至多一个** `active` 切片（对应该主题 `phase`）。  
- 进入下一阶段：当前 `active` → `completed`；新阶段切片创建为 `draft`（或生成后待锁定），再变为 `active`。  
- 历史 `completed` 可展开查看，不可当作当前执行计划编辑（除非产品后续单开「修订历史」——V1 不做）。

### 2.3 Activity（切片内活动）

切片内条目可带活动类型：`learn` | `practice` | `apply`（可空或可选）。

生成时按阶段套默认比重（需求表）；用户可手动增删改单条，**默认局部修订，禁止以整表重生为主路径**。

练习 / 应用切片：清单级字段即可（标题、一句话说明、完成勾选）；不追求课表级精细结构。

---

## 3. 阶段切换流程

```text
用户：进入下一阶段
  → 校验目标阶段全局槽位未满（硬拦）
  → 当前切片 active → completed
  → theme.phase = 下一阶段
  → 新生成该阶段切片（draft）
  → 用户可手改 / 锁定后 → active
```

- 阶段**只**由用户触发（无自动按天数晋级）。  
- 「学习完成」= 成功进入练习期并完成学习切片归档。  
- 回退阶段（应用→练习等）：V1 可不做；若做，需重新占槽校验，本说明标为后置。

## 4. 并发与主焦点

### 4.1 阶段槽位（全局）

统计 `status = active` 且 `phase = X` 的主题数：

| phase | max |
|-------|-----|
| learning | 1 |
| practice | 3 |
| application | 5 |

触顶行为：**硬拦**，展示：当前占用列表 +「切换阶段 / 休眠 / 废弃」腾槽指引。  
`dormant` / `archived` **不占**阶段槽。

### 4.2 主焦点

- 用户手动开关 `is_focus`。  
- 全局 `is_focus = true` 计数：`≤ 3`（硬顶）；`> 1` 时 **强警告 UI** + 写入 **计划漂移事件**（可供 C 栏 / 可视化消费）。  
- 主焦点与 `phase` 正交：练习期、应用期主题也可标为主焦点。

### 4.3 两套约束同时生效

示例：已有 1 个学习期主题时，不可再开第二个学习期（阶段硬拦），与主焦点无关。  
已有 1 个主焦点时再设第 2 个：允许（≤3），但强警告并记漂移。

---

## 5. 与工作台 P / D 的关系

### 5.1 P · 计划

- **替换**「学习计划 / 练习计划 / 应用计划」三入口长期并排、同等维护的假设。  
- 推荐信息架构：  
  - 展示 **当前阶段** + **当前切片**（可编辑）；  
  - **历史切片**折叠只读；  
  - 「进入下一阶段」主操作（含槽位校验）。  
- 学习期切片的共创交互可继续挂接既有「对话共创」原型；练习/应用可用更短的生成 + 手改流程（本设计不强制同一壳）。

### 5.2 D · 执行

- 只从 **当前 active 切片** 取今日任务。  
- 任务类型分布服从切片内活动，间接体现阶段比重。  
- 续跑主题（非主焦点、练习/应用期）以少量任务出现，不与主焦点抢同一强度默认配额（具体每日配额算法后置；原型可用固定示例）。

### 5.3 可视化 / 漂移

至少能看见：

- 各阶段槽占用（1/1、2/3、4/5）；  
- 主焦点列表与数量；  
- 漂移事件条数或最近若干条（主焦点 >1 时产生）。

---

## 6. 反模式（实现时禁止）

1. 三份计划文档需同时锁定才算「P 完成」。  
2. 每阶段强制填满学/练/用九宫格才能进入下一阶段。  
3. 以「应用未成熟 / 主题未毕业」硬拦新学习期（槽位规则已覆盖带宽）。  
4. 练习/应用切片做成第二份 20 小时精课表。  
5. 静默突破 1+3+5 或静默设置第 4 个主焦点。

---

## 7. 原型范围建议

高保真优先演示：

1. 单主题：学习切片完成 → 进入练习 → 归档 + 新练习切片；  
2. 全局：学习槽已满时硬拦；  
3. 主焦点从 1 增到 2：强警告 + 漂移记录可见；  
4. 历史切片只读。

可用双主题示例：如「矛盾论」（练习续跑）+「革新学习方法」（学习主焦点）。

---

## 8. 开放问题（本说明不关闭）

1. 练习/应用切片的最小字段定稿与完成判定。  
2. 练习/应用是否复用对话共创壳，或仅「生成草案 + 手改」。  
3. 每日任务在多主题间的配额算法。  
4. 阶段回退与切片「解锁重做」是否需要。
