## 二、三层点击路径说明书（17 步）

### 主路径：进入 → 今日执行

1. 浏览器打开 `home.html` → L1 首页
2. 看到「今天」区 3 条跨主题任务 + 「我的主题」2 张卡片
3. 点击「革新学习方法」主题卡 → `theme-overview.html`（L2）
4. 看到主题阶段、核心掌握摘要、今日任务入口
5. 点击「进入执行」主 CTA → `theme-work.html`（L3·执行模式）
6. 看到今日任务为主焦点区，可勾选/进入
7. Activity Rail 可随时点击「今天」→ 回 L1

### 分支路径：从 L1 直进执行

8. L1 首页 → 点击「今天」区某条任务 → 直达 L3 执行模式

### 计划模式

9. L2 或 L3 → 切换到「计划」Tab → 看到「打开共创」和「阶段管理」入口
10. 点击「打开共创」→ `learning-plan-cocreate.html`
11. 共创页点击返回 → 回到 L3 作业面
12. 点击「阶段管理」→ `theme-plan-phases.html`
13. 阶段页点击返回 → 回到 L3 作业面

### 复盘与改进

14. L2 或 L3 → 切换到「复盘与改进」Tab → 看到复盘摘要 + 「完整复盘」入口
15. 点击「完整复盘」→ `weekly-review.html`
16. 复盘页点击返回 → 回到 L3 作业面

### 新建主题

17. L1 → 点击「新建主题」→ `new-theme-intercept.html` → 可回 L1 或继续进入阶段页

## 三、各层「有什么 / 刻意没有什么」对照表

| 维度 | L1 入口 | L2 主题看板 | L3 作业面 |
|------|---------|-------------|-----------|
| **回答的问题** | 今天干什么 / 进哪个主题 | 这个主题整体怎样、下一步做什么 | 专注一种模式的操作 |
| **有什么** | 今日任务精简条（2~5）、主题卡片（2~4）、新建入口、槽位小字 | 阶段名、核心掌握摘要、当前切片、今日任务 CTA、风险/漂移提示、L3 入口 | 执行/计划/复盘模式切换、今日任务主区、模式子入口 |
| **刻意没有什么** | PDCA 四栏、大块复盘、共创对话、漂移时间线、KPI 墙、完整槽位管理 | 完整共创对话、完整阶段管理台、完整周复盘表单、多主题混排 | 四栏等权常驻、其他模式的完整内容常驻 |

| **返回行为** | — | ← 返回 L1 | ← 返回 L2 / Activity Rail 回 L1 |

## 四、假设与未做项（7 条）

1. **新建主题后的着陆页**：从拦截页选「继续创建」→ theme-plan-phases，但此时尚无 L3 上下文，phases 返回指向 theme-work 可能让用户困惑。后续应考虑新建流程独立闭环（拦截→phases→首次 L2 →L3），或在 phases 页检测来源动态调整返回目标。

2. **主题卡片数量上限**：L1 主题卡按 2~4 张设计。若用户主题超过 4 个，需确定策略（折叠/滚动/仅显示有今日任务的主题）。当前未实现动态截断逻辑。

3. **「今天」任务来源**：假数据硬编码。实际实现需从各主题今日切片动态聚合，跨主题排序/去重逻辑未涉及。

4. **矛盾论主题的 L2/L3**：当前所有链接指向同一套页面（革新学习方法），矛盾论点击后应展示矛盾论自身的数据。实际需要路由参数或独立页面。

5. **模式切换的 Tab 深链**：L3 三模式 Tab（执行/计划/复盘）通过 JS 切换 DOM，浏览器直开 `theme-work.html` 默认显示「执行」。深链到特定模式（如 `?mode=plan`）当前未实现。

6. **Activity Rail 图标**：当前使用 emoji 占位。实际应替换为 Trae icon 系统中的标准图标。

7. **响应式布局**：本轮桌面优先。移动端适配（堆叠布局/底部 Tab Bar）未涉及。
