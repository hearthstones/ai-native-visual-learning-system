## 一、问题与目标

### 1.1 断点（现状）

三层 IA 已能演示**回访用户**日常闭环（L1 → L2 → L3 执行 / 计划 / 复盘），但**新用户从零**走不通：

1. L1 无空态（永远有假任务与主题卡）
2. 「新建主题」直进槽满拦截页（与空槽新用户方向相反）
3. 共创挂在 L3 计划模式内 →「要共创先有主题、要有主题先共创」
4. 新建后返回指向 `theme-work`，缺少首次 L2 着陆

### 1.2 本轮目标（方案 B + 单页四步向导）

补上冷启动主轴：

**空态 L1 → 创建向导（信息 / 材料来源 / 导入占位 / 核心预览）→ 共创锁定 → 首次 L2 → 进入执行**

### 1.3 边界

| 做 | 不做 |
|----|------|
| 空态 L1、四步向导、首次 L2、与共创/拦截接线 | 真实微信读书 API、真实 LLM |
| 通识 + 技术两种材料占位路径 | 阶段推进 / 第二主题完整演示（属方案 C 后续） |
| 空槽直进向导；满槽仍进拦截 | 重写共创引擎或复盘引擎全文 |
| `.design` 登记 + 浏览器可点通 | 移动端适配 |

## 三、向导四步规格（`theme-create.html`）

顶部轻量步进（`1/4` … `4/4`），**不是**强制关卡进度条；可上一步，不可跳步。

### Step 1 · 基本信息

| 字段 | 规则 |
|------|------|
| 主题名称 | 必填 |
| 类型 | 通识 / 技术，二选一 |
| 一句话目标 | 可选 |

示例预填：名称「革新学习方法」· 通识 · 目标「建立可持续的主题阅读方法」。

主按钮：下一步。

### Step 2 · 材料来源

- 通识默认选中「微信读书」；可选「稍后补充」
- 技术默认「本地笔记 / 链接」；可选「稍后补充」
- 选「稍后补充」时 Step 3 展示空导入态 + 可跳过文案，仍须点确认进入 Step 4（核心可改为「基于主题名的草稿核心」）

主按钮：下一步。

### Step 3 · 导入占位

- **通识**：假书单 2～3 本（如《如何阅读一本书》《刻意练习》…）+「已模拟导入划线/想法 N 条」
- **技术**：假链接/文档列表 2～3 条
- 主操作：「模拟导入成功」→ 进入 Step 4  
- 次要：「跳过，稍后导入」→ 仍进入 Step 4（核心为草稿态，UI 需标明）

### Step 4 · 核心预览确认

- 展示 AI 预抽 **5 条**核心要点（与回访态「革新学习方法」核心语义场一致）
- 允许取消勾选 1～2 条，或就地改一句文案（前端模拟即可）
- 主按钮：**确认核心，开始共创计划** → `learning-plan-cocreate.html`
- 禁止：在本步内嵌完整共创对话或完整课表编辑

## 四、槽位路由规则

| 条件 | L1「新建主题」去向 |
|------|-------------------|
| 学习槽空闲（如 `学 0/1`） | `theme-create.html` |
| 学习槽已满（`学 1/1`） | `new-theme-intercept.html`（现逻辑） |

空态 L1 固定展示 `学 0/1 · 练 0/3 · 用 0/5`，主 CTA 文案建议：**新建第一个主题**（与回访态「新建主题」区分即可）。

## 五、冷启动点击路径说明书（≤15 步）

1. 打开 `home-empty.html` → 见空态引导 + 主 CTA + 槽位 0  
2. 点「新建第一个主题」→ `theme-create.html` Step 1  
3. 确认/微调名称与类型 → 下一步  
4. Step 2 选微信读书（或稍后补充）→ 下一步  
5. Step 3 点「模拟导入成功」（或跳过）→ Step 4  
6. Step 4 确认 5 条核心 → 进入共创页  
7. 在共创中完成若干轮（可用现有示例态）→ 点「锁定学习计划」  
8. 进入 `theme-overview-first.html`（首次 L2）  
9. 看到学习期、核心摘要、今日任务 2 项预览  
10. 点「进入执行」→ `theme-work.html`（执行模式）  
11. 勾选/进入今日任务（前端模拟）  
12. Activity Rail「今天」→ 可回到 `home.html`（回访态示例）或带 1 张主题卡的过渡说明（见假设）

旁路：

- 向导任意步「取消 / 返回」→ `home-empty.html`  
- 回访态满槽新建 → 仍走拦截页（不改业务规则）

## 六、各屏「有什么 / 刻意没有什么」

| 屏 | 回答的问题 | 有什么 | 刻意没有什么 |
|----|------------|--------|--------------|
| 空态 L1 | 我第一步干什么 | 一句引导、主 CTA、槽位 0 小字 | 假任务列表、假主题卡、PDCA、拦截话术 |
| 创建向导 | 主题壳与材料是否就绪 | 当前步表单 + 轻量步进 | 共创对话、完整复盘、阶段管理台、多主题混排 |
| 共创 | 课表能否收敛锁定 | 既有左右栏能力 | 再塞创建四步表单 |
| 首次 L2 | 计划是否就绪、下一步做什么 | 与回访 L2 同壳；强调「计划已锁定」；进入执行为主 CTA | 漂移大块、完整共创内嵌、完整周复盘表单 |
| 拦截页 | 如何腾学习槽 | 现有推进/休眠/废弃 | 空槽用户不应看到本页 |

## 七、与既有页接线约定

| 来源 | 动作 | 目标 |
|------|------|------|
| `home-empty` | 新建第一个主题 | `theme-create` |
| `home`（回访） | 新建主题 | 若演示满槽 → `new-theme-intercept`；可选另加「空槽演示」链到 `theme-create` |
| `theme-create` Step4 确认 | 开始共创 | `learning-plan-cocreate` |
| `learning-plan-cocreate` | 锁定计划 | `theme-overview-first` |
| `learning-plan-cocreate` | 返回（未锁定） | 建议回 `theme-create` Step4；若实现成本高可回 `home-empty` 并在假设中写明 |
| `theme-overview-first` | 进入执行 | `theme-work` |
| `theme-overview-first` | 返回 | `home-empty` 或带一主题的 `home`（二选一，交付时写死并登记） |
| `theme-work` | 返回概览 | `theme-overview-first`（本演示路径）或 `theme-overview`（回访路径） |

`.design`：新页节点 + `data-dom-id` / 相对 `href` 双轨登记，与 IA 改版交付同一标准。

## 九、假设与未做项（≤8）

1. **共创未锁定时的返回**：默认可回向导 Step4；若改动共创壳成本高，允许临时回空态 L1，但须在原型页脚或交付注记标明。  
2. **首次执行后的 L1**：本轮可用链到现有 `home.html` 演示「回访感」；不强制实现「仅 1 张革新学习方法卡」的中间态 HTML。  
3. **核心预览的生成**：纯假数据；不接 Skill 流水线。  
4. **「稍后补充」材料**：仍生成 5 条草稿核心，文案需标「基于主题名的草稿，建议稍后补材料后修订」。  
5. **技术类型路径**：向导内可走通，但共创页示例数据仍以通识「革新学习方法」为主；技术共创内容本轮不另做一套。  
6. **深链 / query**：`?step=`、`?mode=` 可选，不作为验收硬条件。  
7. **移动端**：桌面优先，本轮不做。  
8. **阶段推进与第二主题**：明确不在本轮；满槽拦截仅保证路由不被空槽路径破坏。

## 十、验收清单

1. 从 `home-empty.html` 出发，浏览器点击可到达：向导四步 → 共创锁定 → 首次 L2 → L3 执行。  
2. 空态 L1 无假任务、无假主题卡；主 CTA 明确。  
3. 空槽不进入拦截页；满槽路径仍可达拦截页。  
4. 向导四步可感知切换；未确认核心不能进入共创（主路径按钮控制即可）。  
5. 首次 L2 能一句话说清「计划已就绪 + 今日做什么」；主 CTA 为进入执行。  
6. `.design` 已登记新页与 interactions；相对 href 与 `data-dom-id` 对齐。  
7. 视觉延续 Trae dark token，无第五套视觉语言。  
8. 用户能回答：我现在在冷启动哪一步 / 还是已在三层日常循环。
