## 一、验收否决原因（v1 原型）

用户实测结论（2026-07-29）：

1. ~~工程质感：新增页布局错位、图标缺失。~~ **已由用户在 Trae Work 侧直接修好，本轮规格不再把它当交付项。**
2. **体验方向错**：第二步做成「选来源单选」，而非资料共创；第三、四步「导入占位 / 核心预览」让人迷惑，整条链路不像学习产品。
3. **正确心智**：建主题 = 一次轻量表单 + **三次 AI 共创**（阶梯 → 资料 → 计划），对应十倍速学习 Skill1/2/3，并落在本产品的「学 / 练 / 用」三阶段计划上。

参考交互（资料共创）：对话 [收集资料 · FDE](b6acead6-ee30-4224-b172-112a12b3ca97)——多轮约束（如限中文）、评估用户丢来的链接、否决新闻级水文、收敛到高杠杆清单。

## 二、正确主路径（硬约束）

```text
① 主题信息（表单）
   主题名 · 类型（通识/技术）· 一句话目标
        ↓
② 学习阶梯（AI 共创 · Skill1）
   为当前主题拆 5 级台阶；用户选择「我现在在哪一级」并确认
        ↓
③ 学习资料（AI 共创 · Skill2）
   筛高杠杆资料；可限定范围（如微信读书 / 仅中文 / 仅专业）
   交互参考对话 b6acead6：多轮修订、评估候选、拒绝噪声
        ↓
④ 学习计划（AI 共创 · Skill3 改编）
   产出「学 / 练 / 用」三阶段计划（非一次性吐完就结束）
   收敛后锁定 → 首次 L2 → 进入执行
```

| 步 | 形态 | SKILL / 依据 | 用户主要动作 |
|----|------|--------------|--------------|
| ① | 单页表单 | 产品字段 | 填名称/类型/目标 → 下一步 |
| ② | 左对话 / 右活文档 | `ai-learning-step1-stage` | 看阶梯 → **点选当前级别** → 确认 |
| ③ | 左对话 / 右活文档 | `ai-learning-step2-resource` | 改约束、评估链接、确认 5 资源清单 |
| ④ | 左对话 / 右活文档 | `ai-learning-step3-plan` + 阶段模型 | 确认三阶段计划 → **锁定** |

说明：

- ② 的「阶段」= **学习阶梯级别**（新手→熟练实践者），**不是**主题生命周期的学/练/用槽位。
- ④ 的「三阶段」= 产品主题计划：**学习期 / 练习期 / 应用期**（见阶段与并发需求）；Skill3 的「20% 核心 + 可执行切片」精神保留，但**不要**原样照搬「10 节 × 2 小时」当唯一课表（愿用性：约 30 分钟/天）。
- 冷启动允许「阶梯→资料→计划」顺序推进；回访态 L3 仍可单独重开某一共创，不强制每次重跑全流水线。

## 四、各步界面规格

### ① 主题信息

- 字段：主题名（必填）、类型通识/技术、一句话目标（可选）
- 示例预填：革新学习方法 · 通识 · 建立可持续的主题阅读方法
- 主按钮：开始定位学习阶梯 → ②
- 取消 → `home-empty`

### ② 学习阶梯（Skill1）

- 左：教练对话（每轮 ≤1–2 问）；开场即基于主题给出 5 级阶梯草案
- 右：活文档——5 级列表（级别名 / 应理解什么 / 掌握标准 / 关键概念 / 里程碑 / 自检题等，字段以 SKILL 为准）
- **显式交互**：用户点选「我当前在 Level N」；可改选；确认后才能进 ③
- 禁止：一屏问卷；把阶梯做成不可选的静态说明书

### ③ 学习资料（Skill2）

- 左：共创对话；右：5 个高杠杆资源卡片（8 字段以 SKILL 为准）+ 推荐顺序 + 短路径摘要
- **必须可演示的多轮**（对标 b6acead6，前端模拟即可）：
  1. 首稿 5 资源
  2. 用户加约束（例：限微信读书 / 限中文 / 只要专业向）→ 右侧重筛
  3. 用户丢入一条候选链接 → AI 评估「值不值得进清单」
  4. 用户嫌初级/像新闻 → 换硬核资源
- 通识默认可提示「可限定微信读书」；技术默认链接/课程/文档
- 确认清单 → ④

### ④ 学习计划（三阶段）

- 左：共创；右：活文档分三块——**学习期 / 练习期 / 应用期**
  - 学习期：约数日量级；20% 核心可见；每日约 30 分钟切片（与愿用性一致）
  - 练习期 / 应用期：可先简表 + 可后细化（不追求精巧九宫格）
- 显式「锁定学习计划」；锁定后 → `theme-overview-first`（仅 `from=create`）；回访从 L3 进入时锁定后回 `theme-work`
- 禁止：再塞「导入占位」「核心预览」独立表单步

### 首次 L2 / 建完 L1

- 首次 L2：计划已锁定 + 今日任务 CTA 为主；核心一行摘要即可；去掉漂移大块与底栏三模式抢戏
- 建完后首页：`home-after-first`（或等价状态），**禁止**再回到「学 0/1 · 新建第一个主题」空态

## 五、点击路径（验收 ≤16 步）

1. 开 `home-empty` → 新建第一个主题  
2. ① 确认信息 → 进入阶梯共创  
3. 浏览 5 级 → 点选当前级 → 确认  
4. 进入资料共创 → 见 5 资源  
5. 模拟加约束（如微信读书）→ 清单更新  
6. （可选）评估一条候选 → 清单微调  
7. 确认资料 → 进入计划共创  
8. 见学/练/用三阶段草稿 → 微调一句 → 锁定  
9. 首次 L2 → 进入执行  
10. Rail「今天」→ `home-after-first`（有主题卡与今日任务）

## 七、假设与未做项

1. 真实 LLM / 微信读书 API 仍不接；共创用前端状态机模拟多轮。  
2. Skill 原文路径以本机 Claude skills 为准；Trae 若读不到，以提示词内嵌的字段清单为准。  
3. 练习/应用期详细共创可在锁定后从 L3「计划」再进入；冷启动④给可读的三阶段骨架即可。  
4. 技术主题资料共创示例可用「革新学习方法」通识叙事为主，技术分支有切换即可。  
5. 不新开设计语言；不把已修好的壳推倒重来。

1. 主路径语义为：信息 → 阶梯共创 → 资料共创 → 三阶段计划共创 → 首次 L2 → 执行。
