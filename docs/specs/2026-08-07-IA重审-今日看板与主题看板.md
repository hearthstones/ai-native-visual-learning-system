## 一、一句话

日常只有两面：**今日看板（任务）** 与 **主题看板（主题容器：信息 / 计划 / 执行 / 复盘）**；取消独立作业面作为第三日常层。

---

## 二、表面对照

| 表面 | 路由（现状，实现前） | 回答的问题 | 有什么 | 刻意没有 |
|------|---------------------|------------|--------|----------|
| **今日看板** | `/` | 今天干什么、拉什么进今天、进哪个主题 | 今日承诺、可做队列、主题轻卡、槽位/漂移、新建 | 完整共创、完整阶段台、完整复盘、主题内计划编辑 |
| **主题看板** | `/themes/:id` | 这个主题怎样、在主题内做事与改方向 | 主题信息、计划管理、**任务执行**、复盘改进 | 与今日对等的「又一作业 App」；跨主题任务墙 |

旧 L3（`/themes/:id/work`）退出主路径；能力迁入主题看板对应区块。路由可暂时保留，但需求不再承认其为对等第三层。

---

## 三、主路径说明书

### 3.1 日常：打开 → 做事（着陆 B）

1. 打开 App → **今日看板**  
2. 在今日承诺 / 可做队列上完成选集（加入今天、按建议填入、移出今天）  
3. 对今日任务 **就地勾选完成**（不跳转）——着陆 **B**  
4. 需要主题语境时，点主题轻卡 /「进入主题」→ **主题看板**  
5. 在主题看板内可继续操作该主题任务执行区、计划、复盘  
6. Rail / 返回「今天」→ 今日看板  

### 3.2 日常：从主题进入

7. 今日看板主题入口 → 主题看板（含信息 / 计划 / 执行 / 复盘；不要求先点「进入执行」再进第三层）  

### 3.3 计划 / 计划书 / 复盘

8. 主题看板 · 计划管理 → 计划书通读、阶段、共创/修订（子页返回主题看板）  
9. 主题看板 · 复盘改进 → 周复盘与改进（子页返回主题看板）  
10. 壳层若保留「复盘」快捷，须落到同一复盘能力，不另造作业壳  

### 3.4 冷启动结束后

11. 计划锁定后着陆 **今日看板**  
12. 否决默认「摘要看板 → 再进独立作业面」；否决点今日任务默认跳进主题看板

## 四、主题看板四块（职责）

| 区块 | 职责 | 迁入的旧能力 |
|------|------|----------------|
| 主题信息 | 阶段、阶梯摘要、漂移等 | 旧 L2 摘要 |
| 计划管理 | 计划书、阶段、共创/修订 | 旧 L2 次要链 + 旧 L3 plan |
| 任务执行 | 可做 / 今日相关任务勾选与展开 | 旧 L3 execute |
| 复盘改进 | 周复盘与改进 | 旧 L3 review + 壳层复盘入口 |

交互保真度（分区 / Tab / 锚点）实现期再定；约束是**用户不感到又进入第三层 App**。
