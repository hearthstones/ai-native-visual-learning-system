# 主题看板 · 视觉结构（对齐今日看板）

> 日期：2026-08-07  
> 状态：定案，进入实现  
> 需求锚点：[IA 重审 · 今日看板与主题看板](./2026-08-07-IA重审-今日看板与主题看板.md)  
> 原则：向今日看板借语言；四块职责保留，**不**四 Tab 平权

---

## 1. 一句话

主题看板 = **单列主区「本主题可做」**（当前切片全部未完成活动）+ 短「下一步与资料」+ **折叠**的计划 / 复盘；顶栏一行 meta。

## 2. 主区列表范围

**该主题当前切片里所有未完成 Activity**（含已承诺到今天的）。  
不是「仅今日承诺」，也不是跨主题队列。

| 展示 | 来源 |
|------|------|
| 主列表 | `ActiveSlice.activities` 中 `done === false` |
| 「今日」徽标 | 若存在当日 `DailyTask` 关联该 activity |
| 完成勾选 | 有今日任务则 `toggleTask`（同步 Activity）；否则 `toggleActivity` |

## 3. 页面骨架

```text
← 今天
主题名
meta（阶段 · 阶梯 · 时长 · 切片）
目标一行（可选）

查看  [阶梯] [资料] [计划]  [主题计划书]
调整  [阶段管理] [修订共创]

本主题可做 …
复盘与笔记（折叠）
```

### 按钮关系

| 分组 | 按钮 | 作用 |
|------|------|------|
| **查看** | 阶梯 / 资料 / 计划 | 各自独立页面（`/document/ladder|resources|plan`） |
| **查看** | 主题计划书 | 全书通读 + 导出 HTML |
| **调整** | 阶段管理 | 学/练/用推进、切片与槽位 |
| **调整** | 修订共创 | 修订已锁定的计划共创 |

查看三钮与调整用系统 `ds-btn`；主题计划书用 secondary 稍强调。分章仍为独立页面。

## 4. 深链（兼容旧 mode）

| `?mode=` | 行为 |
|----------|------|
| （默认）/ `execute` / `info` | 主区可见；计划/复盘折叠 |
| `plan` | 打开「计划与阶段」 |
| `review` | 打开「复盘与笔记」 |

不再使用四 Tab 作为主导航。
