## 一、可点通冷启动路径（14 步）

| # | 页面 | 动作 | 跳转目标 | 备注 |

## 二、各步「有什么 / 刻意没有」短表

### home-empty.html（空态首页）

| 有什么 | 刻意没有 |
|--------|---------|
| 空态引导文案「从第一个主题开始」 | 不放功能密集的仪表盘 |
| 阶段槽位提示「学 0/1 · 练 0/3 · 用 0/5」 | 不显示历史数据（没有） |
| 主 CTA「新建第一个主题」 | 不放「跳过建主题直接体验」诱导 |

### theme-create.html（① 主题信息）

| 有什么 | 刻意没有 |
|--------|---------|
| 主题名 / 类型（通识·技能·领域）/ 目标三字段 | v1 的「材料来源单选」 |
| 顶栏轻量步进「信息 · 阶梯 · 资料 · 计划」 | 不是考试进度条，不显示百分比 |
| 「开始 AI 共创」主 CTA | 不做 Step2-4 导入占位/核心预览 |

### theme-cocreate-stage.html（② 学习阶梯）

| 有什么 | 刻意没有 |
|--------|---------|
| 左栏对话：AI 首稿 → 用户可追问/调整 | 不做单选表单选阶梯 |
| 右侧活文档：5 级阶梯（理解→掌握→概念→里程碑→练习→自检） | 不超过 5 级，不做 10 级 |
| 点选「我当前在 Level N」确认机制 | 不确认不能进 ③（硬约束） |
| 每轮最多 1-2 个追问约束 | 不做一屏问卷 |

### theme-cocreate-resources.html（③ 学习资料）

| 有什么 | 刻意没有 |
|--------|---------|
| 多轮 1：加范围约束（微信读书）重筛 | 不做一次性返回全部 |
| 多轮 2：评估用户粘贴候选 / 否决过浅资源 | 不做静默通过，会拒绝新闻/初级噪声 |
| 5 条高杠杆资源，每条 8 字段 + 排序 + 短路径 | 不堆 20 条资料列表 |
| 被否决资源保留痕迹（对话中可见） | 不隐藏 AI 的否决理由 |

### learning-plan-cocreate.html（④ 学习计划）

| 有什么 | 刻意没有 |
|--------|---------|
| 右侧活文档分「学习期 / 练习期 / 应用期」三段 | 不做无分段的扁平课表 |
| 锁定前 CTA 文案为「锁定计划」（未生效态） | 锁定前不假装已生成今日任务 |
| 锁定后分流：from=create → overview-first | 不直接跳回 home |
| 每日约 30 分钟，7 天学习期 | 不用「10×2 小时」当唯一课表 |
| 返回：from=create 时可回 ③ | 不做单向不可逆 |

### theme-overview-first.html（首次锁定看板）

| 有什么 | 刻意没有 |
|--------|---------|
| 锁定成功提示（check-circle 图标） | 不堆回访看板的进度/漂移/并发信息 |
| 今日任务主 CTA「开始第一天」 | 不放模式切换 tab（执行/计划/复盘） |
| 核心精神一行（5 条核心 + 阶段/天数） | 不做完整看板布局 |

### home-after-first.html（建完后今天）

| 有什么 | 刻意没有 |
|--------|---------|
| 1 张主题卡（革新学习方法 · 学习期） | 不回 home-empty（禁止） |
| 今日任务 2 项（可点进作业面） | 不显示空态引导 |
| 「新建主题」入口（次要 tertiary 按钮） | 不做发现/推荐/社区 |

## 三、假设与未做项（8 条）

1. **SKILL 文件路径不可用**：三个 SKILL.md 未在 workspace 找到，阶梯/资料/计划字段按规格描述 + 通用方法论实现，未使用原始 SKILL 字段定义。
2. **示例数据为硬编码**：「革新学习方法」的阶梯、资料、计划均为前端静态数据，无真实 LLM 调用，对话多轮通过预设轮次切换模拟。
3. **from=create 参数为模拟**：`.design` 交互跳转不含 query string，锁定分流逻辑在 HTML 中以文案+目标页面体现，未实现真实 URL 参数解析。
4. **微信读书范围约束为演示**：资料共创的「限定微信读书」仅为对话演示，无真实 API 集成或书库检索。
5. **未做移动端深度适配**：共创页双栏在 < 720px 下仅有基本折叠（activityrail 隐藏），未做对话/文档的移动端独立交互。
6. **L3 单进未实现独立入口**：回访用户直接进入计划共创的快捷路径未单独建页面，当前依赖 `theme-work.html` 的「打开共创」按钮（已有但未在本轮改动范围内验证）。
7. **锁定后不可逆**：锁定动作无「解锁/重新共创」的回退路径，用户锁定后只能通过作业面重新进入共创修改。
8. **周复盘/阶段切换页未改动**：`weekly-review.html` 和 `theme-plan-phases.html` 保持原状，未按新流程调整交互。
