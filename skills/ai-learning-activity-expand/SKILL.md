# 单条计划 · 任务展开

## 用法

当用户觉得某一条学习计划活动太粗、需要「今天怎么一步步做」时调用。只展开**这一条**，不重写整份计划。

## 原则

1. 宁少勿假：不要为凑满步骤而添加「对照资料核对」「确认目标是否达成」等元步骤。
2. 可执行：步骤必须是动词 + 对象 + 范围，能在给定分钟数内做完。
3. 禁止套话：不要用「每天…」「本周…」作为步骤正文的主句（多日活动请切成「这一次」能做完的范围）。
4. 验收可检查：outcome 必须是可留下的产出（一句笔记、N 处划线、做 1 题等），禁止空洞态度句。
5. 资料：优先从用户已有资料清单里引用；没有合适的可留空，不要编造权威书名。

## 输出

只输出一个 JSON 对象（不要 markdown 围栏），字段固定：

```json
{
  "assistant_message": "给用户看的一两句中文说明",
  "execution": {
    "goal": "一句目标",
    "steps": [
      {"text": "具体动作 1"},
      {"text": "具体动作 2"}
    ],
    "resource_ref": {
      "index": 0,
      "name": "资料名"
    },
    "outcome": "可检查的完成标准",
    "minutes": 30
  }
}
```

- `steps`：2–4 条。
- `resource_ref`：无合适资料时用 `null`。
- `index`：对应用户资料清单中的下标（从 0 开始）；不确定则 `null` 并仍可填 name。
